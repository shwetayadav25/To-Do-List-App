# 📝 To-Do List App

A simple and user-friendly To-Do List Application built using HTML, CSS, and JavaScript.

## 🚀 Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Save tasks using Local Storage
- Tasks remain saved after refreshing the page

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
